## 🎬 What is Sunday?

Sunday is a **voice-controlled AI assistant** for Windows. Talk to it — it listens, understands, and does things for you:

- 🔊 **Control volume** — up, down, mute, set to any number
- 📂 **Open/close apps** — Chrome, Spotify, VS Code, Notepad, and 30+ more
- ⏯️ **Media control** — play, pause, next, previous song
- 🔒 **System commands** — lock screen, screenshot, shutdown, sleep
- 🎵 **Play songs** — 45+ Hindi & English songs library
- 🌐 **Open websites** — Google, YouTube, GitHub, Gmail, etc.
- 🤖 **Answer questions** — powered by Google Gemini AI
- 🌅 **Tell time & date**
- 😴 **Dual mode** — sleep and command

All **hands-free**, all with **your voice**.

## 🚀 Quick Start

### Prerequisites

- **Windows 10 or 11**
- **Python 3.12** ([Download here](https://www.python.org/ftp/python/3.12.9/python-3.12.9-amd64.exe))
- **Internet connection** (for Gemini AI + Google Speech)
- **Microphone** (built-in or external)
- **Speakers/Headphones**

> ⚠️ **Important:** Python 3.12 specifically. Newer versions (3.13+) have compatibility issues with some libraries.

### Installation

#### **Step 1 — Install Python 3.12**

1. Download: **[Python 3.12.9 (64-bit)](https://www.python.org/ftp/python/3.12.9/python-3.12.9-amd64.exe)**
2. Run the installer
3. ⚠️ **Tick "Add python.exe to PATH"** (critical!)
4. Click "Install Now"
5. Restart your PC

#### **Step 2 — Install VS Code (Recommended)**

Download: [code.visualstudio.com](https://code.visualstudio.com/)

#### **Step 3 — Get Sunday Folder**

Place the `Sunday` folder anywhere on your PC. Example: `D:\Code\Sunday`

Open it in VS Code: **File → Open Folder → Select `Sunday`**

#### **Step 4 — Open Terminal in VS Code**

Press `` Ctrl + ` `` (backtick) to open the integrated terminal.
